# Russian in Diagrams

Russian grammar for English speakers. Every topic from the Russian school textbooks for grades 7–11 (Belarus), grouped by subject, with a diagram, a plain English explanation, translated examples and a quiz. Includes a Start here page (Cyrillic alphabet, how to read the diagrams, the six cases) and a glossary.

Russian edition: https://abyzanna.github.io/russkiy-po-shemam/

- `index.html`: course map and sections
- `theme.html?t=ID`: all topics of one section
- `start.html`, `glossary.html`
- `data/gradeN.js`: topic content; `data/themes.js`: section grouping
- `assets/app.js`: renders topics and diagrams

Serve with any static server, e.g. `python3 -m http.server`.
